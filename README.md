# About Me

A static personal portfolio and blog built with Astro, React islands, Motion,
and Tailwind CSS.

## Commands

```sh
npm install
npm run dev
npm test
npm run build
npm run preview
```

Profile copy lives in `src/data/profile.ts`. Blog posts and projects live in
`src/content/`.

The production build uses the `/aboutme/` base path for GitHub Pages at
https://gerlis18.github.io/aboutme/. Pages source should be **GitHub Actions**.
